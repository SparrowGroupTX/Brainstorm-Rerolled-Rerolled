The ordinary chooser already scores each affordable offered Joker for every
eligible sale against the original full row. The defect is that it returns only
the generic best purchase, then replacement_sale_plan applies a different final
row utility. A voucher can discard all replacement candidates; a purchase rating
threshold can also remove an endpoint before its final merit is compared.

Repair returns the existing Joker candidates separately and compares their final
replacement merits. Whole-family use is bounded to<=6 owned/<=3 shop offers;
held consumables are unchanged and retain the existing whole-inventory valuation.
No new graph, resource transition, scorer, ordering algorithm or score reservation
is needed: all endpoint calls already occurred. Existing context caching, original
row baselines, limits and global incomplete-budget fallback are retained. A known
unsupported endpoint prevents selecting a prefix of the new family. Larger rows
retain legacy scope, with an explicit receipt-scope reason. Packs retain their
existing path. Objective admission and survival domination remain in force.

Candidate adjusted purchase rating is not added to final utility; cost and its
existing full original-row adjustment are applied once. Pinned sales are rejected.
Unknown effects, Eternal victims, removed Credit Card allowance and Negative
capacity stay protected. A proposed sale remains one action and advice is refreshed;
there is no stored action queue. The current broad shop graph is not expanded.

targeted01 selects the complete replacement with identical4360 calls and ratio6.

not reconstructed from a captured game. This proves the defect class/local
arbitration difference, not optimal play or historical rescue. Earlier probes are
preserved: the nonexpired row preferred the voucher; the cheaper expired-row case
already selected replacement, a useful counterexample to an unconditional defect.
