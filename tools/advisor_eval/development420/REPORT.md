## Changes

Death inventory value now includes a bounded improvement term from the strongest
qualified public source and its useful recipients. Rank, suit, enhancement,
edition, seal and existing Joker context use the same target-value function as
actual copying. Unknown population identities receive no such credit. Saturated
identical upgraded populations have no copying recipients. This strategic value
does not promise when that source will be drawn or certify a current hand.

A sole ordinary full-slot Empress can now receive a bounded sell-then-buy Death
comparison. It compares the complete funded inventory endpoint, charges actions
and cash, preserves rental/discard reserves, and requires fresh purchase ranking
to select the same offer. Negative stock cannot create a slot by losing its own
capacity. Unknown/unaffordable offers and a supported superior Blueprint purchase
prevent that sale. This adjacent candidate-generation gap was found in source;
it was not the cause of the actual free-slot missed Death above.

Held Death can justify continued funded Standard/Spectral exploration after modest
upgrades and at ante7. The reserve is the maximum of interest-cap-plus12,
25-plus-unavoidable rental/discard costs, and15-plus-copy acquisition costs.
A Glass/Polychrome/Red-Seal Club King is a practical stopping point for the extra
search bonus; it is not a proof no contextually better source exists. Revealed
choices still compete normally and weak plain additions can be skipped. No
unseen pack identity, future income or winning outcome is credited.

Actual Death target selection already recomputed source/recipient pairs on every
fresh observation. No stale-source defect was demonstrated. New regressions
verify a stronger newly acquired source replaces the old preference, physical
left/right reordering occurs first, and hidden/not-held sources are not selected.

The known-clear path can now compare a legal Death preparation even when a smaller
discard is available. It projects the actual copy, tests a smaller two/three-card
rank anchor, and calls the existing retained-discard proof on that endpoint. The
new batch must be larger. All work fits the existing six-call development budget
and the unused portion of the twelve-call growth budget. It returns only the
copy or its required hand reorder; after the actual action, fresh advice must
reestablish the discard. Last valuable Perkeo source, paid-discard, Glass,
population, original held Gold/Blue and Arm guards remain. This does not prove arbitrary discard-first,
future-draw or repeated-Death sequences. Such broader hands remain ordinary
search work; no guarantee of drawing a pair/full house/Flush Five is invented.

Canonical Seltzer now qualifies for additive scoring-card-order safety, including
its last remaining play and exact Holo+10 edition. It retriggers each scoring
card once; discarding does not spend its lifetime. Complete Chad rotations remain
required. Modified counters/edition amounts are rejected. This does not admit
arbitrary editions or held-card effects such as Raised Fist.

Burnt now receives explicit teacher growth opportunity value over at most three
remaining rounds, respecting discard availability, Burglar, final Water/Chicot
and perishability. Editions remain valued separately. This repairs the missing
valuation term without making rarity an automatic priority; a mature Red Card
can still win. Other objective profiles retain their old valuation contract.

A narrow teacher opening can spend one nonwinning single-card play to improve
the category of a full five-card first Burnt discard. It requires a winning
single-card anchor, a known neutral public deck, ordinary Small/Big blind (or
disabled boss), canonical core row, at least two hands, all discards unspent,
and enough deck for every remaining full batch after the setup draw. Every
possible one-card replacement in the unordered population is classified; expected
hand-level value pays for the lost hand income/action cost. The desired category
is not guaranteed. Three score calls fit the existing twelve-call growth cap.
The actual setup must be strictly nonwinning; its exact after-play state must
retain a draw-independent clear, all discards and cash. Only one opening setup
is allowed. Existing useful nonwinning Yorick-copy arrangements remain valid.

When copying Yorick makes that setup win immediately, the existing legal Burnt
arrangement can be used first. Setup scoring uses that actual reduced row;
retained-finish scoring separately restores the proven legal scoring row. Each
reorder, play and discard is an actual separate action with fresh observation.
This path never scores the fishing play using a hypothetical scoring order.

Phase copying now follows full-discard teacher preference and removes its old
small-growth/action-time veto. Blueprint, Brainstorm and their combined chain
copy Burnt for the actual first discard; paired physical discard states must
still agree in every non-level resource, and batch size cannot decrease. After
the first discard, a bounded two-score comparison restores Yorick copies when
the same held play improves and complete after-play resources agree, normalizing
only scored chips and physical row order. A current discard's resources must also
agree when restoration precedes it. Existing pin, visibility, callback and budget
boundaries remain. Unsupported rows do not receive an invented safe chain.

First-discard category/copy count, desired fishing hand, no-guaranteed-target
status and restored scoring comparisons now have public compact receipts. Actual
hand levels and discards_used come from fresh observations; a projected receipt
is not a claim that its callback settled. No invented persistent run memory is used.

Optional surplus spending now begins above$40 at Antes5–6, then above$25 from
Ante7 onward, plus reserved rental/discard costs. It chooses one affordable visible
pack or refresh and reevaluates; indivisible prices cannot cross that floor.
Supported ordinary purchases retain their existing priority.

Public receipts expose the known source behind a Death purchase and the bounded
