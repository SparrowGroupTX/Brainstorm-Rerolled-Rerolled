## Intended measurement contract

The collector is opt-in through the existing public-recording preference. It uses finite monotonic elapsed wall times, bounded counters/histograms, bounded slow-frame examples and bounded decision receipts. It emits no more than one compact summary per five seconds, with explicit empty public context so summaries cannot capture full snapshots. Ordinary frames accumulate scalars in memory. It neither performs a solver call nor adds a per-frame disk write. Exact metric names, histogram boundaries, slow-frame/decision entry caps and integration hashes are pending final code review.

Planned measured regions include original `Game:update`, checkpoint/search/journal/advisor/auto/legacy update subphases, update total and frame gap; original draw, advisor HUD draw and draw total; snapshot capture, fingerprint construction, worker resume and decision lifecycle; and journal observation, encoding, append and total. Journal append includes existing compression/hash/readback work. Nested measurements are inclusive and must not be summed as disjoint time. Update total excludes its trailing bounded timing-summary emission; that emission is recorded separately. These measurements are elapsed wall time, including preemption or waits, not CPU utilization or GPU training/inference.

Every new ordinary journal event retains its UTC timestamp and sequence while adding an event-entry monotonic anchor with explicit available/unavailable status. The anchor precedes observation, encoding and append. Missing, throwing, invalid or backward clocks remain explicit and must not fail gameplay or logging. Monotonic values are comparable within a process/session, not across restarts. Existing archive hashes, append verification, segment/storage/event limits, action-to-callback linkage and retry protections remain.

Summary emission must preserve any measurements added by its own encoding/append, reporting them in a later window; failed writes must not silently consume queued measurements. Disabled telemetry must not trigger full snapshots, extra game actions, logs or worker work. Instrumentation must preserve original callback arguments, return values and exceptions. It must not alter deterministic policy input, action ordering, resource guards, computation ceilings, native CPU preferences or animation speed.
