# Prospective public fingerprint export

The auto-run controller uses an exact serialized snapshot for internal freshness and pending-action comparisons. `snapshot.card` retains raw rank, suit, base and ability fields even on concealed cards, with downstream scoring responsible for concealment safeguards. The snapshot sorts the remaining deck by identity, so this specific string does not expose next-draw order. It can still contain concealed hand/outside identities and the exact remaining-pile assignment, plus catalog forecast data.

The existing journal redacts concealed identities in `context.snapshot`, but previously wrote controller `details.fingerprint`, `details.before` and `details.after` strings directly. A further defined path is `manual_checkpoint_continuation.interrupted_action.fingerprint`. These bypassed the intended public-only observation boundary. No new log decoding or source experiment was needed to establish that code path.

The product logging boundary now replaces only those defined exports with an opaque record: `schema=1`, `kind='snapshot_fingerprint_sha256'`, `status='available'`, original `byte_length`, and lowercase hexadecimal `sha256` of the exact original Lua string bytes. The default implementation uses the existing game hash API with SHA256; an injected test dependency follows the same hexadecimal-result contract. Missing, failed or invalid hashing produces an explicit `unavailable` record with a static reason. It never emits a raw fallback or an exception message that could echo the input.

Every internal full-string comparison, pending-action identity, execution recapture, ordinary snapshot, advice, action, timing, token and checkpoint accounting rule remains unchanged. A shallow exported event and a separate checkpoint interruption table prevent changes to the supplied controller record. Other nested user strings are not rewritten. Historical files and decoder output remain exact and untouched. This is a prospective public-data correction, not a claim that a digest can losslessly reconstruct a historical fingerprint.
