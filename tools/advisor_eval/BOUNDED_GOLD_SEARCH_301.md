# Bounded normal Gold search and aggregate decision budget

The user-started Quick Gold run menu searches for Yorick and Perkeo in the
starting Charm pack, with Burnt and a copy Joker by Ante5. Red or Zodiac Deck,
Gold Stake, maximum native CPU and no Perishable targets are explicit. The copy
slot can accept Blueprint or Brainstorm. Optional distinct missing-Joker counts
use the loaded profile's known Gold history, with an inclusive Ante window.
Zero additional required targets avoids unnecessary collection constraints.

Search runs on a LOVE thread. A native27s deadline leaves3s of the requested30s
for dispatch and cleanup; actual runtime also rejects late results. Stop or
manual input invalidates found receipts and requests cancellation; exclusive
ownership remains until actual thread exit. Search cancellation never pretends
to kill an unknown worker. The UI closes through the original callback, waits
for a settled state, and only an explicit start can replace the current run.
No search, new run or automatic play begins on installation or module load.
The separate auto-run controller is still being integrated after301.

All criteria describe conditional no-reroll stock/Buffoon encounters. They do
not guarantee affordability, actual acquisition, retention or survival. The
native query assumes complete unlocks; actual player unlock equivalence is not
qualified. Six unsupported fresh-run collection targets remain excluded from
the optional direct-target quota. The independent seed cursor does not touch
game RNG. Screened counts represent completed parallel chunks, not exhaustive
contiguous ranges. Native waiting-time estimates for the combined query remain
unavailable. Quota counting stops at the required distinct count.

C01's frozen300 audit found13 decisions above the aggregate140000 ordinary
score budget (maximum169367). The301 decision integration clamps each later
specialist to the remaining total, while retaining its smaller local cap and
complete-candidate/world guards. Search keeps its existing allocation; this
small repair introduces no new reservation policy. Fast-clear70, shop50000 and
consumable25000 limits remain. Tests cover incomplete comparison refusal and
an exactly affordable complete ordering comparison. This cap repair does not
inherit C01's outcome.
