# Priorities for learning prototype 355

Read `SESSION_RESET_355.md` and the exact experiment ledger first. This is an
isolated GPU learning pilot; installed runtime remains2.154.0-alpha. Job outcomes
and closure supersede any pending wording below.

1. All355 experiments are closed. T02 failed development and final evaluation;
   no model is promotable. Start from the documented failures, not another copy
   of the same PPO run. Preserve unsupported and censored outcomes as unknown.
2. Build a lossless public-state/action training interface for reviewed decisions
   across **all phases**, using the existing advisor and human examples as fallible
   teachers. Exact candidate mapping, phase/order, inventory, goal status and
   decision-time public information must survive conversion. A losing run may
   contain useful local decisions; it is not an all-correct demonstration.
   First audit the existing logs and converter with manufactured fixtures; no
   new advisor/source evaluation is silently authorized.
3. Treat simulator fidelity as the promotion gate. Our verified scoring/source
   mechanics remain the reference. Repair or explicitly exclude discrepancies;
   neither unit tests nor fast throughput qualify a full game engine.
4. Keep curricula within Red/Gold Perkeo/Yorick. Start with verified short-horizon
   tasks at the learner's ability, including support retention, Yorick development,
   Perkeo copy preparation and final-boss/new-sticker conversion. Reconstructed
   public states require sampled hidden worlds and explicit source qualification;
   player saves and actual hidden RNG are not training inputs. A curriculum may
   use declared auxiliary goals, but final evaluation remains full-start distinct
   new stickers. Retain a competent behavior prior during RL, refresh/calibrate
   value targets, and preserve success/failure and teacher/learner distinctions.
5. Remove redundant reorder decision paths via a public-state-aware option or
   cycle guard that preserves meaningful order changes and re-observes after
   game events. Do not solve liquidation by permanently forbidding sales of
   named Jokers: final support retirement is part of the target task. Neither
   proposed change is implemented by355. Research modern curriculum, selective
   exact search/reanalysis and memory before spending more VRAM.
6. Any runtime promotion requires meaningful evidence against the installed
   policy, exact legality/mechanics checks, the ordinary release/install process
   and source-calibrated terminal validation. Do not install an unqualified model.

Broader unfinished goals remain real-time Completionist++ acquisition/retention,
all20 challenges, Jokerless, Knife's Edge, and the earlier strategic priorities
in `NEXT_PRIORITIES_354.md`. Old quotas remain closed. A completed pilot does not
authorize an unlimited training service, source jobs, seed search or automation.
