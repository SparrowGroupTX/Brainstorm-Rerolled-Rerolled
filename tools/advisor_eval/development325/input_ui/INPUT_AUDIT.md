The shared collection product also cancels requests when profile/Gold population, its input token or run identity changes, and refuses launch while menus, transitions, saves or controller locks are active. These checks are not generic click cancellation. They must preserve stale-result rejection and the original search deadline even if root changes waiting/reconciliation behavior. The production `collection_search_input_generation` value currently has no writer in the repository; direct stop calls are the ordinary-input cancellation path. A native worker must never gain a fresh budget merely because a menu/input changed.

Proposed narrow product interface for UI is `AutoRun:resume()` without options, plus a read-only session/resumable status field supplied by root. Resume must reuse the stopped session/current run and its original counters; it must never delegate to `start(options())`. The page can fit Resume, Stop and Full status in one existing row using three compact buttons, avoiding another vertical row. Its existing Start controls remain clearly labeled as new searched runs. A persistent HUD Resume requires an explicit read-only resumable flag; without one, the page Resume is sufficient and avoids inferring lifecycle from status text.

Relevant fixture entrypoints are `advisor_collection_core.lua` (actual extracted input wrappers), `advisor_collection_status.lua` and `advisor_startup_ui.lua` (collection controls), `advisor_gold_layout.lua` (bounded layout), `advisor_runtime.lua` (drawn HUD Stop latch), `advisor_checkpoint_runtime.lua` (manufactured verified save/load), and root's `advisor_auto_run_product.lua`/controller tests. Meaningful cases include ordinary inputs preserving active ownership, no duplicate native request on Ctrl+A, option edits preserving current session, explicit Stop dispatch, Resume calling only resume with no new options, stale drawn Stop never executing, and every checkpoint validation/retry protection remaining intact.

Drafting and staging await agreement on root's lifecycle API and file ownership; this note grants no source/search/complete-attempt authority.
